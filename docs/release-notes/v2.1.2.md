# CFST-GUI v2.1.2

## 变更摘要

### Windows 安装器

- Windows 安装器从 NSIS 改为自绘的 Go 安装器（Wails v3 + WebView2）：560×380 无边框窗口，深色单色版式、等宽字体展示路径与版本号，安装进度在同一窗口内以日志控制台和 2px 进度条就地切换，安装与卸载界面均为简体中文。发布脚本改为编译并签名 `cmd/installer`，不再依赖 NSIS 工具链。
- 保留 `/S`、`/D=` 静默参数与 winget/choco 批量部署能力，并新增 `--no-desktop`、`--no-launch`；卸载器改为安装器自身副本，卸载界面与安装器一致。
- 安装器底部新增“查看许可证”入口：安装前即可在窗内阅读 GPL-3.0 原文与第三方声明，文本直接读取安装包内嵌的 `LICENSE` / `THIRD-PARTY-NOTICES.md`（只读 `/api/legal` 接口）。安装时同一份文本会写入安装目录。
- 安装与卸载安全加固：校验注册安装位置，只删除应用自有文件；程序和卸载器先写临时文件再原子替换，安装失败或提交前取消会恢复原文件；兼容清理旧 NSIS 版在公共桌面、公共开始菜单创建的快捷方式。

### 许可与发布

- 许可明确为 GPL-3.0-only 并补齐版权声明：新增 `THIRD-PARTY-NOTICES.md` 与可复现的第三方清单生成、校验脚本；前端产物、安装目录、Linux/macOS 发行包、GitHub Release 与 APK 均携带 `LICENSE` 与第三方声明，Android Release 另校验签名身份与法律资产。
- Windows 发布签名默认允许自签证书：本地缺少证书时生成临时自签 PFX，CI 在缺少签名 Secret 时按 `windows_self_signed` 输入生成临时证书；`SignTool` 警告只记录日志、不再中断构建。设置 `CFST_WINDOWS_ALLOW_SELF_SIGNED=0` 可恢复强制受信任证书链。
- `windows-signed-install.ps1` 支持显式传入 `-AllowLocal`，可在管理员本地环境复现签名安装验收；CI 仍使用临时 GitHub-hosted runner 执行完整安装与卸载闭环。
- Windows 质量任务新增 `pnpm check:notices`，第三方清单过期即失败；Android Release task 守卫收窄，`ktlintCheck` 不再要求 Release keystore。

### 安全与稳定性

- 诊断 ZIP 导出对通知密码、Webhook 密钥与鉴权信息脱敏，且不改写持久化配置。
- WebUI 写入统一校验同源请求与 JSON Content-Type，无令牌 API 拒绝非回环 Host；修复首次事件订阅失败后的启动恢复。
- 邮件通知遵循 TLS 配置与取消信号，并增加发送总超时；DNS 替换 CNAME 失败时记录已建地址，并在响应丢失后重新读取服务端状态完成回滚。
- Android 在线更新元数据仅接受官方 HTTPS 来源及受控重定向，限制读取时长与大小；APK 必须通过可信 SHA256 校验，缺少 manifest 时兼容官方资产 digest，避免选择不兼容架构。
- 修复 Linux 构建误包含 Windows 安装器的问题；恢复发布脚本 ShellCheck；Windows 安装版与便携版签名验收改为哈希、时间戳和签名身份一致性校验。
- 修复新 Windows 安装器在含空格路径下卸载后残留 `uninstall.exe` 的问题。

### 修复

- 修复选择旧 NSIS 安装目录时被误判为“非空且非已有安装”的问题：旧卸载项缺少 `InstallLocation` 时从 `UninstallString` / `DisplayIcon` 还原目录，并识别 `icon.ico`、`LICENSE` 与 `THIRD-PARTY-NOTICES.md` 等应用自有文件。
- 回退 2.1.1 引入的“启动同步链让到首帧之后”。该改动把 `loadConfig` 推到首帧之后，启动同步可能在用户已经点过界面之后才落地，并覆盖刚选中的 COLO 过滤模式；冷启动收益保留首包裁剪与启动屏淡出两处，这一处让位撤销。

### 版本与构建

- 默认版本统一为 `2.1.2`，Android `versionName` 为 `2.1.2`、`versionCode` 提升为 `20102`。
- 版本同步脚本与发布预检都覆盖安装器默认版本，避免手动 `go build ./cmd/installer` 再显示 `vdev-win64`。
