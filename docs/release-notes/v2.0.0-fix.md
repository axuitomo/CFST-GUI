# CFST-GUI v2.0.0-fix

## 变更摘要

- 修复桌面/WebUI bridge 通道判定：通道只由宿主身份决定，普通浏览器页面不再等待 Wails 运行时注入；WebUI 健康探测移出应用挂载路径并增加 3 秒超时，代理无响应时页面仍可正常启动；401 响应会清除鉴权探测缓存并重新判断。
- 将 Windows WebView2 用户数据目录固定到应用数据目录，避免安装目录或启动目录变化导致缓存、权限和文件锁问题。
- 修复设置页帮助提示在触屏设备上无法可靠关闭的问题，并恢复移动端标题、摘要与卡片尺寸。
- 收紧前端平台边界门禁，覆盖 Wails runtime 与 WebUI API 的替代写法；补充 bridge、运行时注入、事件重绑和 WebUI 健康响应契约测试。
- 修复 Quality 与 CodeQL 的 Android SDK 初始化：直接使用 GitHub runner 预装的 cmdline-tools，避免 `android-actions/setup-android@v3` 请求已下架的 `tools` 包；Windows 存储迁移测试改为等待异步迁移真正完成。
- 修复 Vapor HTML 检查正则的大小写覆盖，并统一 LF 工作区约束。
- Android `versionCode` 提升为 `20001`，可覆盖安装 v2.0.0（`20000`）。

## 发布渠道

`2.0.0-fix` 含预发布后缀，GitHub 将其标记为 Pre-release，不会替换 `v2.0.0` 的 latest 状态。应用内更新检查读取 GitHub Releases latest，因此该版本需从发布页手动下载。
