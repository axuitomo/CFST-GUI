# CFST-GUI v1.9.0

## 变更摘要

- MCIS 搜索探针改用 `GET` 获取 Cloudflare trace，并恢复 TLS 证书校验、`TraceURL` 目标选择和 COLO allow/deny 过滤，失败探针不再进入 Top N。
- MCIS 前缀树新增最大节点数与最小信息增益约束，提高拆分稳定性；利用阶段采用确定性排序，同一引擎实例可安全顺序复用。
- 桌面端、WebUI、Android 和 CLI 的配置、任务、存储、归档、上传与通知能力进一步收敛到共享 `internal/appcore` 服务，减少跨端行为差异。
- Android 文件分享与更新下载路径收紧到应用私有范围，发布和质量工作流同步更新。
- Release、Android resubmit、Container workflow、Wails、Go runtime 和 Android 默认版本号统一提升到 `1.9.0`，Android 默认 `versionCode` 提升到 `10900`。
- 主 Release workflow 发布 Windows、Linux WebUI、Android、update manifest 和 GHCR 多架构镜像 `ghcr.io/axuitomo/cfst-gui:1.9.0`、`ghcr.io/axuitomo/cfst-gui:v1.9.0` 与 `latest`。
