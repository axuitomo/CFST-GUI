# CFST-GUI v1.9.6

## 变更摘要

- 强化代码质量与静态检查体系：新增 golangci-lint、actionlint、stylelint、markdownlint、根目录 ESLint 以及 Android ktlint/detekt 检查，配套补充 `.editorconfig`、`.golangci.yml`、`.markdownlint-cli2.jsonc`、`eslint.config.mjs`、`detekt-baseline.xml` 等配置文件。
- 修复 Go 与 Android 端 lint 发现的问题：errcheck 返回值处理、导入排序、SharedPreferences 现代 API 用法、zip 头时间字段（`Modified`）、WebDAV 状态判断、调试日志轮转错误处理等。
- 完善 CI 流水线：CodeQL 增加 Android 工具链支持（JDK 24、Go、pnpm、Android SDK/NDK），恢复 Android 与 WebUI 质量任务并统一 Gradle wrapper 调用方式。
- 改进 Windows 安装器（NSIS 脚本）与 Android 插件命令 JSON 处理。
- 前端新增 stylelint、markdownlint-cli2、typescript-eslint 等检查依赖与 lint 脚本。
- 文档定义最低环境基线（Go 1.27、Node 26.7、pnpm 10.34.5、JDK 24、AGP 9.3.0、Gradle 9.5.1、SDK 37、NDK 29 等），并统一仓库文档换行规范。
