# CFST-GUI v2.0.2

## 变更摘要

- 新增多渠道上传通知：在 Telegram 之外增加 Webhook（通用 URL、钉钉、企业微信）和 Email（SMTP）渠道，上传成功与任务失败分别推送；通知配置随配置快照保存并参与备份与 WebUI 同步，各渠道相互独立，单个渠道失败只记录告警与调试事件，不阻断其余渠道。
- 新增 MICS 抽样预算与并发、下载成功数上限：`probecore` 新增 `mcis.budget`、`mcis.concurrency` 和 `download_success_limit` 字段（默认 `0` 表示自动或关闭，负值归一化为默认值并给出警告）；前端设置页与配置快照同步这些字段，下载阶段达到成功数上限后停止派发新 IP。
- 前端冷启动同步期间禁用任务动作：读配置期间看板展示缓存的展示数据，`startupSyncing` 为真时禁用启动、终止、暂停和恢复，避免用户针对过期状态操作。
- 修复 HTTP/2 传输超时：自定义 `DialTLSContext` 下 `TLSHandshakeTimeout` 不生效，改为在握手内部设置截止时间，并转发 `ResponseHeaderTimeout`；补充 ALPN 拒绝与握手截止时间两条此前未覆盖的测试路径。
- Windows 新增系统代理支持（`internal/httpclient/sysproxy_windows.go`）。
- Android 探测并发默认值下调并补充平台提示；通知权限的 API 33 判断收拢进权限表达式，避免在低版本查询 `POST_NOTIFICATIONS`。
- 界面修复：首次运行流程与引导更清晰、设置页显示模式持久化、删除数据源二次确认、启动配置延迟加载自动重试、桌面摘要卡片保持单行、DNS 控件与内容对齐、Android 键盘弹出时高度稳定。
- 新增动画预览页与 `dashboardCache` 仪表盘缓存（含单元测试）。
- 工程化：`internal/configvalue` 重命名为 `internal/config`；以 oxlint + oxfmt 取代 ESLint + Prettier；升级依赖与工具链并整理 `go.sum` 校验和。

## 发布渠道

`2.0.2` 为纯数字版本，GitHub 将其作为正式 Release 并接管 latest；应用内更新检查读取 GitHub Releases latest。Android `versionCode` 保持 `20002`（与 v2.0.1 相同），可直接覆盖安装 v2.0.1。
