# CFST-GUI v2.1.5

## 变更摘要

本版是一次修复与工程收口版本，用户可见行为只在受限网络上发生变化：阶段 2 追踪不再被 QUIC 握手吃掉预算；同时把分支与发布两条 CI 路径的质量门禁合并成一份定义，避免“发布时才第一次报错”。

### 稳定性修复

- 修复第二阶段追踪在 UDP/443 被封或被代理截走的网络上几乎全部淘汰。追踪请求此前沿用全局 `auto` 协议，先做一次 QUIC 握手，这次握手失败可以耗时 1.5 秒以上，吃满 `stage2_timeout_ms`（默认 1000 ms）后 TCP 回退拿到的 context 已经过期，整批 IP 按 `context deadline exceeded` 淘汰。现在追踪与来源抓取一致固定走 TCP（都是小文本请求，HTTP/3 没有收益），并新增用例锁定「`CFST_HTTP_PROTOCOL=h3` 时追踪仍然成功」的行为。
- `pnpm check:fast` 对变更的 `scripts/*.sh` 在本机装有 `shellcheck` 时改跑 `shellcheck -x`，不再是只查语法的 `bash -n`；SC2221/SC2222 这类规则不会再等到发布门禁才第一次报出。
- `scripts/checks/doctor.sh` 新增 `shellcheck >= 0.10.0` 断言，本机旧版本会以 `mismatch` 提示升级。

### 质量门禁

- 质量门禁收敛为 `.github/actions/quality-gate` 单一 composite action：工具链版本（Go、Node、pnpm、Java、Wails、shellcheck 与 Go lint 工具）、`doctor.sh --strict`、`ci-local.sh` 以及 `CFST_REQUIRE_*` 覆盖都只在这里定义。`Quality` 与 `Release` 两个工作流都 `uses` 它，tag 推送不会再跑分支推送没跑过的检查。
- 前端格式检查不再按改动集裁剪：`format-check.ps1` / `format-check.sh` 固定用 `git ls-files --cached --others --exclude-standard` 列全量文件，`.gitignore`（`node_modules`、`dist`、`wailsjs`、`.vite` 缓存）自动生效；改动集裁剪曾让格式漂移只在某个工作流里暴露（v2.1.4 的 `DnsSelfTestPanel.vue`），因此 `CFST_FORMAT_SCOPE` 变量随之移除。

### 版本与构建

- 默认版本统一为 `2.1.5`，Android `versionName` 为 `2.1.5`、`versionCode` 提升为 `20105`。
- 发布脚本、安装器默认版本与 Release / Container / Android 工作流的版本输入同步到 `2.1.5`。
