# CFST-GUI v1.9.5

## 变更摘要

- 修复 Android 文件选择、目录授权与持久化存储访问，并收紧更新文件的 FileProvider 暴露范围。
- 加强 Android APK 清单、FileProvider 资源和构建产物校验，修复资源保留与重复声明问题。
- 完善 Windows、WebUI 与 Android 发布工作流的 Wails bindings、依赖安装、签名和产物校验流程。
- 更新 Android 构建工具链与 Capacitor 依赖，并补充 PowerShell 7 优先的开发协作规范。
