# CFST-GUI v2.0.6

## 变更摘要

### 界面与交互

- 重整输入组和来源卡片布局；输入组设置、输入组管理和来源编辑支持平滑展开，并减少切换时的页面位移。
- 页面导航改为短时淡化过渡；设置页支持单条 Cloudflare 分流规则折叠，并记忆分区展开状态。
- 统一浅色/深色主题及启动页颜色，隐藏滚动条外观但保留滚动操作。
- 停用输入源时移除重复说明；仍显示来源错误、读取状态和预览结果。

### 稳定性与质量

- 防止较早完成的配置保存响应覆盖用户随后修改的输入组设置。
- Windows 签名增加可信时间戳，发布流程验证签名状态和时间戳。
- 新增 Chromium 组件测试、页面 DOM/Aria 回归及桌面/手机明暗主题截图基线，并接入 CI。
- Android `versionCode` 更新为 `20006`。
