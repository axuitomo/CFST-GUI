# CFST-GUI v2.0.0

## 变更摘要

- 设置页新增分区帮助说明：通用设置、数据与存储、网络与任务、自动化与导出、通知配置、安全与诊断各分区标题旁新增 `?` 帮助按钮，悬停或聚焦即显示该分区说明，点击可固定/取消固定，便于新用户理解每个分区管什么；分区标题右侧的状态摘要标签移入分区内部展示，整体收紧页面与卡片间距，视觉密度更一致。
- 前端静态资源缓存策略统一：入口 `index.html` 强制 `no-cache`、带内容哈希的 `/assets/*` 使用 `public, max-age=31536000, immutable` 长缓存，避免覆盖安装/升级后 WebView2 与浏览器继续读旧 `index.html` 进而拉取旧哈希的 JS/CSS（表现为“升级之后还是旧前端”）。
- 前端来源可诊断：启动时打印当前前端来源——`[frontend] proxying live Vite dev server ...` 表示走 Vite 实时源码，`[frontend] serving embedded frontend/dist snapshot ...` 表示使用二进制内嵌快照；内嵌的 `frontend/dist` 缺少 `index.html` 时直接报出可操作的修复指引（先 `pnpm --dir frontend build` 再重新构建 Go 二进制），不再出现含义不清的 “no index.html” 或静默回退旧页面。
- Windows 桌面/CLI 启动模式拆分随 2.0.0 正式纳入发行资产：桌面发行版（`-H windowsgui`，无控制台）收到 `--cli` 或 CFST 兼容参数时弹窗说明并退出，引导改用命令行版 `cfst-gui-cli.exe`；命令行版注入 `launchMode=cli`，不带参数时输出用法提示而不是启动桌面窗口；非 Windows 与非桌面发行构建仍直接进入 CLI。
- 前端质量门禁收口：新增 `vapor-mode`（Vapor 全树一致性检查）与 `frontend-boundary`（平台收敛边界检查）门禁，接入 pre-commit、`scripts/checks/check.sh` 与 CI，前端改动必须在 Vapor 模式与跨端边界约束内通过。
- 开发配置与工具：`wails3 dev` 不带 `-config` 时默认读取 `build/config.yml` 并拉起原生桌面窗口（与 `build/config/wails.yml` 保持一致）；新增 `scripts/dev/free-dev-port.mjs`，自动清理上一次开发会话强杀后残留并占用 Vite 端口的孤儿进程，避免“wails3 dev 没反应、窗口还是旧的”。
- 文档重构：`docs/reference` 拆分为五个聚焦文档——`api-contracts.md`（后端命令、WebUI API、Bridge 与事件）、`capabilities-and-flows.md`（功能与运行链路）、`configuration-and-data.md`（配置与数据结构）、`external-interfaces.md`（外部接口与输入输出）、`limits-and-code-location.md`（已知限制与代码定位），替代原先单篇大文档。
- 依赖与工具链保持 v1.9.8 基线：JDK 25、AGP 9.3.2、NDK r30、Wails `v3.0.0-beta.20`、pnpm 12.3.4、vite 8.3.0。

## 已知遗留

沿用 v1.9.8 列出的安全审计遗留（更新链路 TLS 校验与完整性哈希同信道下发、配置接口明文回传密钥、诊断与源文件接口路径未收敛、WebUI 令牌 URL query 形式无限流、WebDAV 允许 `http://` 明文 Basic 认证），本轮未处理，留待后续版本。
