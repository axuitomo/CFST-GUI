# CFST-GUI v1.9.1

## 变更摘要

- MCIS 探针流程支持独立的阶段限制、并发执行与实时进度展示，前端任务状态和暂停、恢复、取消交互同步完善。
- 统一桌面端、WebUI、Android 与 CLI 的配置快照、任务快照、探测阶段和上传通知处理，补充跨层测试覆盖。
- 优化 MCIS trace 探测、COLO 过滤、失败结果处理以及前缀树搜索流程，提高探测稳定性与可观测性。
- 发布工作流、容器工作流、Android 构建配置、Wails 配置和运行时默认版本统一提升到 `1.9.1`，Android 默认 `versionCode` 提升到 `10901`。
- 清理已完成的 MCIS 升级计划文档及临时探测结果文件。
