# CFST-GUI v2.1.0

## 变更摘要

### DNS 推送平台

- 新增阿里云 DNS 与 DNSPod（腾讯云）两个平台，和 Cloudflare、DNSHE 并列：阿里云走云解析 RPC 接口（AccessKey ID/Secret，`SignatureVersion 1.0` + HMAC-SHA1），DNSPod 走腾讯云 API 3.0（SecretId/SecretKey，`TC3-HMAC-SHA256`），记录按 A/AAAA + TTL 覆盖同步。
- 三个「完整域名」平台（DNSHE、阿里云、DNSPod）推送前都先用完整域名在账号下做最长后缀匹配；域名不在账号下时直接报错，不会写入其它域名。同一记录名上的 CNAME 由共享对账逻辑统一替换。
- `dns_providers[].provider` 增加 `aliyun`、`dnspod`，并接受 `alidns`、`dndps`、`tencentcloud` 作为读取别名；旧配置与旧键继续可用。
- 设置页「DNS 推送平台」的每张平台卡片默认折叠：标题行显示平台名、记录名与「已就绪 / 待补全 / 已停用」，点标题展开字段，新添加的平台自动展开；添加按钮从 2 个扩到 4 个。

### 探测策略界面

- 三个阶段的桌面排版收口，不再留半行空白：第一阶段把 TCP 延迟区间从独占整行压到两列、与丢包率同排，8 个字段整齐占满三行；第三阶段把「输入上限」从「底层调优」上移到「核心目标」，底层调优因此变成 6 项、正好两行；单 IP 测量窗口的「预热 / 正式测速」等分撑满整行。
- 「阶段1 TCP 超时」改称「第一阶段 TCP 超时」，与阶段标题一致。

### 移除（不兼容变更）

- 移除 CLI 模式与 CFST 兼容参数：`internal/app` 只保留 GUI 与 WebUI 健康检查两条启动路径，传入 `--cli` 或旧参数会打印提示并以状态码 2 退出；Windows 发布产物只保留桌面 `cfst-gui.exe`，不再构建命令行版。
- 移除 HTTPing 延迟测速模式：探测固定走 TCP 延迟 + 追踪 + 文件测速，`probe.httping` 与 `strategy=http-colo` 不再生效；追踪阶段继续使用 `trace_status_code`、`trace_cf_colo`、`trace_cf_colo_mode`。
- 移除「屏蔽 403」「屏蔽 1034」两个开关：403 / 1034 一律直接淘汰该 IP，不重试、不计入连续失败冷却。`probe.ignore_403`、`probe.ignore_1034` 不再读取，旧配置里的这两个键会被忽略；`stage.reject` 与 `probe.edge_rejected` 的 `ignored` 字段保留，值恒为 `true`。

### 追踪与淘汰

- 阶段 2 追踪也识别 1034：追踪响应是 403 且正文含 `error code: 1034` 时当场淘汰该 IP，不再浪费一次文件测速；`probe.edge_rejected` 事件的 `stage` 因此可能是 `stage2_trace`。
- 403 / 1034 的正文嗅探从 64 字节放宽到 512 字节（`Range: bytes=0-511`），避免标记靠后时被误判成普通 403。

### 桌面与移动端

- 桌面端支持把输入文件拖到 exe 上：文件作为本地输入源加入列表（不自动写盘），保存配置后生效；应用已运行时拖放会转发给现有窗口。
- 通用 HTTP 客户端支持显式 Proxy 策略，DoH 只跟随显式配置的 `HTTPS_PROXY`，不再跟随系统代理；调试日志脱敏字段新增 `api_key`。
- Android 上传通知状态识别新增的 DNS 平台 provider。
