# CFST-GUI v2.0.1

## 变更摘要

- 修复 Android WebView 渲染进程被系统回收后整个 app 进程被终止的问题：`MainActivity` 接管 `onRenderProcessGone` 并返回 true，回到前台后再重建 Activity 与 WebView；Go runtime、正在运行的探测任务和事件序号保持不中断，任务快照不再被标记为 `recovery_required`。
- 消除 Android 冷启动、WebView 重建和 `recreate()` 之间的白屏：启动窗口、Activity 窗口背景与 WebView 底色取同一颜色，`frontend/index.html` 内联的首帧启动画面兜住 Vue 挂载前的空档。
- Android 原生界面跟随应用主题：前端解析出的主题写入 `localStorage`（供首帧启动画面使用）并通过新的 `SetSurfaceTheme` 桥接方法同步给原生，`MainActivity` 按缓存主题选择窗口主题、刷新窗口与 WebView 底色；深色主题取 `#09090B`，冷启动第一帧由 `res/values-night` 跟随系统深色模式。
- Android 12 及以上启动窗口改用应用图标（此前显示系统通用图标）。
- 清除 Code Scanning 告警：zip/tar 解压改用 `filepath.IsLocal` 守卫（`go/zipslip`）、通知用的 `PendingIntent` 改为显式组件（`java/android/implicit-pendingintents` ×2），并通过 `.github/codeql/codeql-config.yml` 排除 `node_modules` 依赖源码（`java/xss`、`java/error-message-exposure`）；顺带删除两个从未被读取的通知 `Intent` action。
- Android `versionCode` 提升为 `20002`，可覆盖安装 v2.0.0-fix（`20001`）。

## 发布渠道

`2.0.1` 为纯数字版本，GitHub 将其作为正式 Release 并接管 latest；应用内更新检查读取 GitHub Releases latest，因此 `v2.0.0` 与手动安装的 `v2.0.0-fix` 都能在应用内检测到该版本。
