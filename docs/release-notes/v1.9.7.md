# CFST-GUI v1.9.7

## 变更摘要

- Android 在线更新的版本比较改用安全的 `Long` 解析，超出范围或未知版本段不会导致更新检查崩溃。
- Android 更新响应现在要求 GitHub Release 提供 `tag_name`，缺失时返回明确错误。
- 前端 bridge 将非对象命令响应归一化为稳定错误结果，并在 Android 上根据 Capacitor 平台直接选择原生 bridge。
- 发布构建目录和脚本按 build、checks、dev 分类，默认发布集合覆盖 Windows amd64、Linux amd64/arm64 与 Android arm64。

## 验证

- `bash scripts/checks/release-preflight.sh 1.9.7 --allow-dirty`
- `bash .git/hooks/pre-commit`
