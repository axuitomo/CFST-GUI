# CFST-GUI v2.0.4

> 本文件是 2.0.4 的骨架，内容填完前 `scripts/checks/release-preflight.sh 2.0.4` 会因为“待补充”占位符而失败，不要用它发版。

## 撤回背景

[v2.0.3](./v2.0.3.md) 的 GitHub Release 已转为 draft 撤回，代码、`v2.0.3` 标签与原有发行资产保留在仓库中。2.0.4 在修复该缺陷后重新发布，公开 latest 在 2.0.4 发布前保持 `v2.0.2`。

## 变更摘要

- 待补充：2.0.3 的缺陷修复条目（现象、影响范围、修复方式）。

## 发布渠道

- Android `versionCode` 需从 `20003` 提升到 `20004`，`scripts/build/version-bump.sh 2.0.4 --android-code 20004` 会同步默认版本号。
- 纯数字版本会作为正式 Release 接管 latest。

## 验证

- 待补充：`bash scripts/checks/release-preflight.sh 2.0.4 --run-checks` 与实际执行的检查项。

## 发行资产

- `cfst-gui-windows-amd64.exe`：Windows NSIS 安装器
- `cfst-gui-windows-amd64-portable.exe`：Windows 便携版
- `cfst-gui-android-arm64-v8a-release.apk`：Android arm64 Release APK
- `cfst-gui-update-manifest.json`：在线更新资产清单
