# CFST-GUI v2.1.3

## 变更摘要

### DNS 多平台读取与推送

- DNS 记录读取新增「读取平台」选择：可切换到设置页已保存的 Cloudflare、DNSHE、阿里云 DNS 或 DNSPod，不再只能读 Cloudflare；读取仍为只读，未补全凭据或记录名的平台会给出配置错误提示。
- DNS 分流设置对所有平台开放：四个平台都能在共享筛选后按规则拆分记录名、记录类型和规则 Top N，结果页按当前选中平台显示分流状态。
- DNSHE「子域名」支持填 `test` 这类标签或完整域名。账号下没有同名子域时按 `<标签>.<完整域名>` 解释，例如 `test` + `axuitomo.l.cd` 解析为 `test.axuitomo.l.cd` 并写入该名称，不再报「找不到子域名 test」；账号下存在同名子域或填写完整域名时仍按子域选择处理。推送、DNS 读取页和设置页「当前目标」预览共用同一套解析规则。
- 设置页新增 DNSHE「读取子域名」：拉取账号下的子域名并在输入框中联想选择，展示完整域名与状态；打开 DNS 页时也会静默读取一次，用于自动确定主域名。
- DNS 平台新增「允许修改 CNAME」开关（四个平台通用，默认关闭）。关闭时目标记录名存在 CNAME 会拒绝本次推送并返回 `DNS_CNAME_PROTECTED`，不会删除别名；开启后才按覆盖语义先删除 CNAME 再写入 A/AAAA。
- DNS 页面新增「DNS 平台自检」：选择已启用的平台，在专用测试记录名上依次验证读取、上传 A/AAAA、幂等重推、换血、TTL 属性更新与 CNAME 拦截/替换，跑完自动清理。DNSHE 固定使用主域名（子域 zone 顶点）下的 `cfst-selftest.<主域名>`，不跟随推送记录名；其他平台使用 `cfst-selftest.<推送记录名>`。
- DNSHE 读取页选择「当前域名全部记录」时按整个子域返回记录，不再只返回子域顶点。
- DNS 平台备注名默认跟随平台名称；读取旧配置时备注名为空的条目会回填平台名，仍可手动改成「主域名」「备用」等备注。

### 探测与界面

- 输入组 IP 模式的「随机抽查」统一改名为「MICS 抽样」，同步到输入组摘要、任务阶段标签、Dashboard 抽样进度标题和入门文档；配置键与 `mcis` 模式值、后端行为不变。
- 「实时测速详情」在并发测速 IP 数大于 1 时改为每个在用 IP 一行，展示 IP、COLO、实时速率与平均速率，采样停止后自动移除该行；单并发仍保持四格卡片布局。并发数、采样间隔、表格开关与行 TTL 均按任务启动时的配置快照固定。
- 极速策略跳过下载测速时不再显示空的并发表；实时测试进程按 IP 各保留一条测速日志，测速表改为语义化 `table`，读屏软件可以把速率与表头关联起来。
- 依赖与工具链同步到最新稳定版：前端 `@vitejs/plugin-vue` 6.0.11、Vitest 5.1.1、Playwright 1.65、oxlint 1.94、oxfmt 0.79、Stylelint 18、Capacitor 8.6.2、motion-v 2.13；Go 侧 quic-go 0.65、modernc sqlite 1.62、`golang.org/x/*` 系列；Android 升到 AGP 9.5.1、Gradle 9.9.1、顶层 KGP 2.4.21。Vue 3.6 与 Wails 3.2 只有 RC/夜版，保持原有钉住版本。

### 修复

- 修复 DNSHE 只填子域名、不填记录名时自检在预检阶段报「没有填写推送记录名」的问题：自检入口先按 `subdomain > subdomain_id > record_name` 解析完整域名，DNSHE 适配器按同一优先级选择子域，避免测到与推送不同的目标。
- DNSHE 客户端遇到 429 会按 `Retry-After` 或指数退避重试（最多 3 次）；自检客户端固定 2 秒请求间隔并把子域解析结果缓存到阶段内，避免单次自检超过 DNSHE 默认 30 请求/分钟而中途失败或残留测试记录。
- DNS 平台自检增加进程内单飞锁，重复执行返回 `DNS_SELFTEST_BUSY`，避免两个窗口同时清理同一测试记录名；`wrote_records` 只在本次实际创建或更新记录后为真，不再把清理旧残留计为「已写入」。
- 修复 DNSHE 主域名记录识别：`dnspush.AbsoluteName` 在记录名恰好等于子域名顶点的场景会把完整域名再拼一次（`axuitomo.l.cd.axuitomo.l.cd`），导致 DNS 页按配置名过滤后主域名记录消失；顶点现在原样返回，相对记录名按 `@` 处理。
- 修复 DNSHE 分流推送在只填子域名、不填记录名时跳过主目标的问题；分流目标可覆盖记录名，但必须属于所选子域名，跨子域写入会被拒绝。
- 前端配置归一化不再把 `probe.concurrency.stage3` 固定写回 1，设置页保存或重新加载后「并发测速 IP 数」保持保存值，并维持 1-16 的既有范围。此前被自动写回 1 的配置需要重新设置一次。
- 安卓端的 200ms 进度节流不再连带拦掉 `probe.speed`：并发采样的每颗 IP 都会逐采样更新实时行，不再只显示第一颗。
- DNS 推送的 Cloudflare 入口在缺少探测结果、只带 `ipsRaw` 时直接返回 `DNS_INPUT_EMPTY` 且不发起请求，不再绕过记录类型过滤直接写 A/AAAA。
