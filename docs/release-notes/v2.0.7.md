# CFST-GUI v2.0.7

## 变更摘要

### 探测策略界面

- 三个阶段与 MICS 抽样改为折叠行：收起时摘要直接显示关键取值（端口/并发/延迟区间/丢包上限、状态码/地区码、单 IP 时长/速率依据/结果条数），极速模式下第三阶段整块不渲染，不再显示不生效的下载参数。
- 表单按低端 WebView 约束重做：单位内嵌为输入框后缀（ms、%、MB/s、KiB、秒），值为 0 表示不限制的字段显示「不限制」；丢包率改为整数百分比输入（配置仍存 0~1）；TCP 延迟上下限合并为一行区间，下限不小于上限时标红；阶段 1 超时小于延迟上限时给出警告条与一键同步；端口策略切到「输入源端口优先」后标签改为「回退测速端口」。
- 第二阶段按「阶段准入与 COLO 策略 → 追踪请求配置 → 最终地区码过滤」重排：地区码改为标签容器（回车或逗号批量添加、点 `×` 删除、可套用亚太优选/美西），有效状态码提供 200/204/不限制 胶囊，追踪 URL 在标准模式下降级为备用端点。
- 第三阶段分核心目标、异常过滤、底层调优三层，底层 7 项默认不渲染；最低下载速度旁显示约合 Mbps 并提供 5/15/50 胶囊；预热与正式测速合并为串联组；底部的跨阶段脚注移除，说明改由字段级 `?` 提示承载。
- MICS 抽样自动模式不再显示禁用的 `0`：隐藏输入框并显示推导结果（预算为第一阶段候选池上限 ×3，并发同步第一阶段 TCP 并发），切到手动时预填该值，摘要行显示「手动(值)」。

### 桌面与移动端

- 桌面端 WebView2 profile 从漫游的 `%APPDATA%\CFST-GUI\webview2` 迁到本机缓存目录 `%LOCALAPPDATA%\CFST-GUI\webview2`，首次启动自动搬迁，域账号与开启配置漫游的部署不再同步浏览器缓存。
- `probe.edge_rejected` 界面事件改为按 250 ms 窗口批量下发，并把快照落盘并入每秒节流，几千 IP 被 403/1034 拒绝时不再逐条过桥。
- Android WebView renderer 改为 `waivedWhenNotVisible`，切到后台后把回收优先级让给系统内存压力。
- 桌面端、WebUI 与 Android 启动时检查 COLO 词典完整性，缺失或损坏时后台自动补一份，失败写入调试事件并在下次测速提示中说明。

### 修复

- 追踪阶段诊断统计（`reason_counts`、`status_counts`、`samples`）的并发写竞态：此前多个追踪 worker 无锁写同一批 map 与切片，可能导致诊断数字失真，极端情况触发 `concurrent map write` 终止进程。
- 文件测速并发 range 请求共享 HTTP 客户端时，重定向回调并发写“最后一次重定向目标”的竞态。
- 探测 worker 异常退出（panic）不再静默：引擎会计数并在本次结果的 `warnings` 中说明，对应 IP 按失败处理，其余 IP 照常执行。
