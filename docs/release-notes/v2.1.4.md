# CFST-GUI v2.1.4

## 变更摘要

本版以工程结构收敛和质量门禁为主，用户可见行为保持稳定。原计划单独发布的 v2.1.3 未打标签发版，其多平台 DNS 读取、分流推送与平台自检等变更随本版首次发布。

### 多平台 DNS（v2.1.3 内容随本版首发）

- DNS 记录读取支持切换 Cloudflare、DNSHE、阿里云 DNS、DNSPod 四个已启用平台，读取保持只读；分流设置对四个平台开放，结果页按当前选中平台显示分流状态。
- DNSHE「子域名」支持填 `test` 这类标签或完整域名：账号下没有同名子域时按 `<标签>.<完整域名>` 解析并写入，不再报「找不到子域名 test」；账号下存在同名子域或填写完整域名时仍按子域选择处理。
- DNS 平台新增「允许修改 CNAME」开关（四个平台通用，默认关闭）。关闭时目标记录名存在 CNAME 会拒绝推送并返回 `DNS_CNAME_PROTECTED`，不删除别名；开启后才按覆盖语义先删除 CNAME 再写入 A/AAAA。
- DNS 页面新增「DNS 平台自检」：在 `cfst-selftest` 前缀的专用测试记录名上依次验证读取、上传 A/AAAA、幂等重推、换血、TTL 更新与 CNAME 拦截/替换，跑完自动清理；DNSHE 固定落在主域名下的 `cfst-selftest.<主域名>`。
- 输入组「随机抽查」统一改名为「MICS 抽样」；「实时测速详情」在并发测速 IP 数大于 1 时按每颗在用 IP 一行展示。

### 稳定性修复

- 修复 Android gomobile 桥接边界未捕获 panic 会直接终止应用进程：命令处理 panic 现在收回为 `COMMAND_PANIC` 失败信封并记录 `bridge.panic` 事件，前端可以显示原因并保留任务现场。
- 修复 Kotlin `normalizeJSON` 对字符串内控制字符的处理：字符串内 0x20 以下字符转义为 `\uXXXX`，字符串外只保留 JSON 允许的空白，避免 Go `encoding/json` 因裸控制字符拒绝整条响应，也避免错误信息里的换行被静默丢弃。
- `mobileapi` 的 JSON 编码兜底改为全部经 `json.Marshal` 生成，不再手工拼接 JSON 文本，避免引号或反斜杠漏转义。
- 修复 `fast.ps1` 在 WSL 桩环境下 `bash -n` 假失败：优先解析 Git Bash。
- 同步 DNS 多平台读取与自检的 e2e aria 基线，测试不再因可访问名称变化而失败。

### 工程结构与质量门禁

- 前端 `App.vue` 按职责拆出主题、导航、视口、Toast/活动流、下载速率、Android 运行时与选择器、配置持久化、输入源与档案、自动保存、DNS 平台/记录/自检、结果工作区与导出、WebDAV、应用更新、存储健康、COLO 词典、调度、任务同步、启动同步和探测任务等 composables。
- `bridge` 的类型与配置按域拆成子模块并保留门面导出，对外导出集合逐一比对一致；`probeEventApply`、`useResultExport`、`useStartupSync`、`useProbeTask` 二次拆分，并补齐 characterization 测试。
- 运行时代码不再拼接 HTML/CSS/JS/SQL/JSON：安装器 UI 拆为 `index.html` + `installer.css` + `installer.js` 并以 `go:embed all:ui` 提供静态路由；WebUI bundle 的 Docker/Compose/README 模板外置到 `scripts/build/templates/webui-bundle/`；`sqliteprobe` 四条 SQL 外置到 `queries/*.sql` 并用 `go:embed` 注入；动画预览样式按 16 个分区拆分。
- 新增 `pnpm check:fast` 秒级检查闭环：按变更区域只跑受影响的 Go 包与前端检查，无改动时回退为最小全量扫描；pre-commit、`check.ps1`/`check.sh`、CI 与 `pnpm` 均已接线。
- 新增 `pnpm check:stringcode` 字符串拼装防回流守卫，覆盖前端 TS/`.vue` script、Go 生产代码与构建脚本；Go 依赖方向用 depguard 固化为四层，并补齐根入口与 `cmd` 的分层盲区。
- `vue-tsc` 改为增量编译（稳态 7.7s → 5.8s）；Go 定时器/退避类测试加 `-short` 守卫，单包重负载测试 ≤3s。
- `docs/plan` 维护记录按年月归档并新增索引；Android WebView 性能文档迁入 `docs/mobile/performance/`；README 与命令文档同步 `scripts/checks/` 路径。

### 许可证

- `LICENSE` 恢复为 GPL-3.0 逐字原文，移除文件头的项目名、版权行、SPDX 标识和多余空行，避免 GitHub 等平台把整份文件判为「无法识别」；项目版权与 SPDX 标识保留在 `README.md`，第三方归属仍在 `THIRD-PARTY-NOTICES.md`。
- 新增 `pnpm check:license`：按整文件哈希校验 `LICENSE` 未被追加注释、版权文字或第三方声明，也未合并其它协议；quality 工作流与法律文件测试同时守住这条约束。

### 版本与构建

- 默认版本统一为 `2.1.4`，Android `versionName` 为 `2.1.4`、`versionCode` 提升为 `20104`。
- 发布脚本、安装器默认版本与 Release/Container/Android 工作流的版本输入同步到 `2.1.4`。
