# CFST-GUI v2.0.3

> **已撤回**：本版本的 GitHub Release 已转为 draft，代码、`v2.0.3` 标签与发行资产仍保留在仓库中；缺陷修复后随 [v2.0.4](./v2.0.4.md) 重新发布，公开最新版本回落到 [v2.0.2](./v2.0.2.md)。

## 变更摘要

- 新增 DoH 输入源解析：可选 `probe.doh_url`（RFC 8484，`application/dns-message`）同时解析输入源域名和来源 URL 主机名，A/AAAA 并行查询并限制在 4 秒预算内，IPv4 优先；端点传输、HTTP 或解析失败时回退系统 DNS，合法 NXDOMAIN 不回退。DoH 客户端直连（不走系统代理）并固定 TCP，避免 HTTP/3 握手拖垮查询预算；端点必须是 `https://`，非法值会被清空并给出配置警告。设置页提供阿里 / DoH.pub / Cloudflare 预设与自定义输入，CLI 为 `-doh`（留空即默认阿里 DoH）。
- 新增来源请求 ECH：来源客户端按主机维护 TCP 传输，从同一 DoH 端点查询 HTTPS RR（type 65）的 `ech` 参数并挂到 TLS 握手；来源主机自己发布 ech 记录时优先用主机记录。主机无 ech 记录或服务端拒绝 ECH 时回退普通传输，回退后仍校验真实证书。新增 `probe.ech`（默认开启）、`probe.ech_config`（手填 base64 ECHConfigList）和 `probe.ech_domain`（默认 `cloudflare-ech.com`，同时作为 ECH 外层 SNI），CLI 为 `-ech`、`-ech-config`、`-ech-domain`。
- 下载测速并发上限从 1 提升到 16（默认仍为 1），设置页新增“并发测速 IP 数”，超出范围的值钳制到上限而不是静默退回串行。
- 新增 `probe.source_pool_limit`（默认 `65536`，上限 `1000000`）与 CLI `-pool-limit`：负 `ip_limit` 现在表示“展开到上限为止”，COLO 预筛有 8 倍解析预算，聚合候选池达到绝对上限时截断并告警。
- 性能：任务快照写盘按任务合并为每秒至多一次，结果页缓存已解码行并在文件未变时不重复读取与排序；COLO 词典改为索引查询；HTTP/3 失效路径在进程内暂停 30 秒，避免每次探测都重付 QUIC 握手代价。
- 修复远端来源链路：来源文件只走 TCP，避免慢 QUIC 握手吃满 30 秒来源超时后用过期上下文回退；遇到 429/5xx 重试一次并继续切换候选 URL，失败只更新状态文案，不再清空上一次成功读取的时间与数量；全部来源失败时补充直连提示。
- 修复探测与调度口径：阶段在后置检查通过后才计入 `completed_stages`；调度器 `skip_if_active` 窗口内出现的 `PROBE_ALREADY_RUNNING` 记为跳过，不再让历史与下游 DNS/GitHub 状态显示失败。
- 修复配置与来源状态：配置写入串行化，来源状态就地更新，未知字段不再丢失，缺少 `enabled` 键的来源视为启用；域解析按次数（`limit × 4`，钳制 `1024..20000`）与 30 秒累计时长设预算，超限时告警并标出截断。
- 界面：前端只挂载当前 shell（此前桌面与移动外壳同时存在于 DOM），进程条目改用稳定 key；结果页精简并默认按平均速度排序；仪表盘启动回退限定在乐观窗口内；设置页分区展开状态持久化，恢复展开与重新进入设置页不再整页淡入。移除事件发射器遗留的调试输出。
- 修复桌面端通知：前端此前走 Wails v2 的 `window.runtime` 接口，在 v3 宿主下必然抛错，只留下 `notification.desktop_failed` 日志。现在上传结论由 Go 侧在 `upload.notification` 事件上调用 Wails v3 通知服务，主窗口隐藏到托盘时也能收到；通知初始化失败只写 `error-log.txt`，不影响启动与测速。
- 修复 Windows 发行构建：Release 构建与 `task build` 都补上 Wails v3 的 `production` 标签（macOS 的 `wails3 build` 原本会自动追加）。缺少该标签时发行包会编入 Vite 反代路径与调试开关，安装包行为与正式版预期不一致。

## 发布渠道

`2.0.3` 为纯数字版本，GitHub 曾将其作为正式 Release 并接管 latest，该 Release 现已撤回为 draft，latest 回到 `v2.0.2`；应用内更新检查读取 GitHub Releases latest，因此不会提示升级到 2.0.3。Android `versionCode` 提升为 `20003`，可直接覆盖安装 v2.0.2。
