# CFST-GUI v2.0.5

## 变更摘要

### 新增

- 输入源按组管理 IP 模式和 COLO 过滤；输入组会保留这些设置，新增来源自动沿用组配置，兼容旧版来源级配置。
- 新增可自托管的 Cloudflare Worker 探针，提供 `/trace` 与 JSON 响应，可作为追踪端点返回 COLO 和出口网络信息。
- COLO 地点词典合并备用名称来源，改善 geofeed 地点名匹配；备用来源失败时限时回退，不阻塞主要词典更新。

### 变更

- `probe.event_throttle_ms` 开始控制运行时进度事件与阶段日志的共享节流窗口。
- 追踪阶段配置字段统一使用 `trace_status_code`、`trace_cf_colo`、`trace_cf_colo_mode`；旧字段仍可读取，保存时写入新字段。
- 自定义 Host/SNI 不再需要总开关，任一自定义字段非空即生效；旧配置中明确关闭总开关时会清除相关字段，保持原有行为。
- 阶段 3 数量限制为 `0` 时使用默认值 `100`；来源级 IP 数量限制移除，候选数量由 `source_pool_limit` 管理。
- 清理不生效的探测配置字段，并迁移仍可兼容的旧值；COLO 字典过滤与探测配置处理同步调整。

### 修复

- 修复输入组、来源卡片或设置分区展开时滚动条出现导致页面横向跳动的问题。
