# CFST-GUI v2.2.0

## 变更摘要

本版为结果页新增后端持久化本地历史、跨批 IP 去重、国家/地区筛选与 Top-N 复制/导出；Telegram 通知支持自定义 API 地址，上传通知与任务看板新增测速漏斗与阶段淘汰原因汇总；同时将核心包收拢至 `internal/kernel` 并完成前端 `bridge`/`adapters`/`client` 模块拆分。

### 新增

- **结果页本地历史与筛选导出**：每次测速的有效结果自动写入后端存储的结果历史（`result-history.json`，保留最近 30 天、最多 12000 条，按「批次 + IP + 端口 + 阶段」合并），首次启动自动从旧浏览器 `localStorage`（`cfst.result.history.v1`）迁移；顶部工具栏支持切换时间范围（本次结果 / 近 1 天 / 近 7 天 / 近 15 天 / 近 30 天 / 全部），桌面表格与移动端卡片改用滚动窗口渲染。
- **跨批 IP 去重与 Top-N 复制**：跨批次范围默认按 IP（多端口场景按 `IP:Port`）合并最新测速记录并提示周期内测速次数；「国家/地区」筛选器按当前去重数据动态生成，显示格式切换移至列头/卡片图标；新增「复制 IP」与 Top-N 选择器（全部 / Top 5 / Top 10 / Top 15 / 自定义）以及「导出 CSV」入口。
- **Telegram 自定义 API 地址**：新增 `notifications.telegram.api_base_url`（兼容 `apiBaseUrl` / `apiHost` 别名），支持填写自建反代或 Bot API 网关地址。
- **上传通知状态与测速漏斗**：上传通知（Telegram、Webhook、邮件、桌面系统通知）新增 `aborted`（熔断/终止）状态并统一图标文案，正文新增「漏斗：扫描 → 候选 → 通过 → 达标」（`funnel`）与总耗时（`duration_ms`），显示时间改按本机时区格式化。
- **阶段汇总事件与 Android 常驻通知**：每个探测阶段结束发布 `probe.stage_summary` 事件，任务看板展示输入、通过、淘汰条数、耗时与中文淘汰原因明细；Android 常驻通知同步展示当前与上一阶段汇总。

### 修复与改进

- **邮件通知编码与发件人兼容**：`Subject` / `From` / `To` 对非 ASCII 内容改用 RFC 2047 编码并补齐 `MIME-Version: 1.0` 与 `Content-Transfer-Encoding: 8bit`，SMTP 信封只提取裸邮箱地址。
- **结果页可访问性与视觉回归**：修复结果页「国家/地区」列头把显示格式按钮文案并入列头可访问名的问题；视觉回归改用与字体无关的布局断言（`@layout`），移除易受系统字体栅格化差异影响的 Windows 像素基线。
- **核心架构收拢**：核心业务与基础设施包收拢至 `internal/kernel/`，前端 `bridge`、`adapters` 与 `client` 按域拆分并接入架构边界检查。
