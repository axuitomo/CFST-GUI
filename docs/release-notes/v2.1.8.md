# CFST-GUI v2.1.8

## 变更摘要

本版给结果 CSV 加了「国家/地区」列（新旧文件始终对齐），文件测速设了成功 IP 配额时进度条改按配额算；同时修掉阶段 0 过滤漏计输入源内部重复候选、暗色主题取值胶囊白底白字，以及上传通知邮件的头部注入。

### 新增

- 结果 CSV 在「地区码」之后新增「国家/地区」列，写中文国家/地区名（如 `中国香港`、`日本`、`美国`），未知地区码写 `N/A`。任务自写的 `result.csv` 与结果页「导出 CSV」/GitHub 导出同步变成 11 列，口径与结果页的国家/地区列一致。
- 追加写入缺少该列的旧 CSV 时先整份补齐（表头插入新列，历史行按各自的 `地区码` 补国家名，其余列与 BOM、文件权限保持不变）再追加；无法解析的旧文件保持原样，仍按原样追加。
- 文件测速设了「达到成功 IP 数后停止」时，`probe.progress` 额外携带 `qualified_target`，进度条按 `passed / qualified_target` 计算；进程日志同时给出「已处理 / 候选总数」与「目标 passed/downloadTarget」两个口径，配额已经满足而候选还没跑完时不再看起来像卡住。

### 修复

- 阶段 0「过滤」把单个输入源内部的重复候选（含 IPv6 `/64` 去重）也算进来，`#端口` 跟随保留下来的那条候选；此前同类重复只让候选数变少，过滤计数不动。
- 上传通知邮件的 `From`/`To`/`Subject` 在拼装前过滤 CR/LF 与空字节，配置里带换行时不能再拼出额外的 SMTP 头；新增 `TestEmailNotificationStripsHeaderInjection` 用本地 SMTP 夹具锁定该行为。
- 暗色主题下设置页取值胶囊的选中态改用靛蓝底色，不再白底白字。

### 变更

- 进度日志的判断迁到 `ProbeRuntime.ShouldLogProgress`，按十分位档位前进触发。进度回调本身已节流，落盘只是其中一个零散子集，按整除判断几乎永不命中；改成档位后每个阶段仍能落到约 10 条进度日志。

### 维护

- CodeQL 的 Go 分析增加 `windows-latest` 一条：`//go:build windows` 的安装器、快捷方式、系统代理、fileio 等文件此前在 Linux 下被构建标签排除，永远不进数据库，现在按 `os` 跑 Ubuntu 与 Windows 两条分析并给 Windows 结果单独的 category。
- 按规则 ID 关闭 `go/path-injection`、`go/command-injection`、`go/email-injection` 三条规则，关闭理由与重开条件写在 `.github/codeql/codeql-config.yml`：本仓库只会重复报同一批已逐条登记豁免的结果（`emailHeaderValue` 已过滤 CR/LF，但 CodeQL 的 `go/email-injection` 未定义 sanitizer），其余规则与其他级别照常上报。
- `changed-check` 枚举嵌套 shell 脚本改用 `find`：`scripts/*.sh` 在没有任何匹配时会让 `bash -n` 与 shellcheck 以 127 退出，后续 Go、前端和文档检查因此从未真正执行。
