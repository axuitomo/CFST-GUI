# CFST-GUI v2.1.9

## 变更摘要

本版把输入源名称规则按主流优选清单重建，并禁止同一链接出现多个输入源；同时补齐暗色主题下输入源页新增提示用到的语义色。

### 新增

- 输入源名称规则按 [bestcf 优选清单](https://bestcf.pages.dev/) 的「优选IP BestIP」「优选网站」重建，覆盖 CM / 天诚 / ZhiXuan / WeTest / HostMonit / IRCF 等 40 余条名称映射。数组顺序即优先级，`CM`、`CM 1`、`CM API`、`天诚 1`–`天诚 5` 这类同系列名称先匹配更具体的链接特征，通用短 token 放在最后；同一链接只留一条规则（`stock.hostmonit.com` 归 HostMonit，不再叫 CFYes）。
- 同一链接只保留一个输入源：判定时忽略协议前缀、末尾斜杠与大小写差异（`example.com/ips.txt` 与 `https://example.com/ips.txt/` 视为同一链接），第一个出现的来源保留，后续重复项在输入源页标出重复提示，预览按钮与保存一并被阻止；空链接与内联来源不参与判定。
- 链接失焦即提示重复，比等到保存被阻止更直接；自动保存（脱敏 Token 静默模式）遇到重复项只标红不弹 toast，手动保存给出「保存被阻止」的状态提示并写入活动记录。

### 修复

- 通用来源命名跳过 `ipv4`/`ipv6`/`all`/`mini`/`best`/`ips`/`txt`/`csv`/`list` 这类排序与格式片段，`/ircf/ipv4.txt` 这类镜像链接取到来源名而不是 `Ipv4`。
- 暗色主题补齐输入源页新增提示用到的语义色映射：成功/危险/警告的 `50`–`80` 底色与 `100`/`200` 描边、`text-rose-600`/`text-red-600`/`text-amber-800`/`text-amber-900` 与 `sky` 系列，以及 `hover:bg-rose-50`、`hover:bg-slate-100`。显式校验失败描边（`border-rose-400`）改用高饱和的 `danger-text`，不再用半透明的 `danger-border`。
