# 快速上手

本文只覆盖一次测速前最常用的四步：设置导出目录、处理 COLO 词典、设置输入源、启动测速。

## 1. 设置导出目录

1. 打开“设置”页。
2. 展开“导出设置”。
3. 在“导出目录”中点击“选择目录”，选择用于保存 CSV、测速文件和调试日志的目录。
4. 按需调整“文件名”，默认会导出为 `result.csv`。
5. 保存配置。

桌面端和 WebUI 使用普通文件目录；Android 使用系统 SAF 授权目录。清除导出目录后，应用会回到默认导出位置。

## 2. 处理 COLO 词典

1. 打开“设置”页（普通设置即可，不需要切到高级设置）。
2. 展开“通用设置”里的“COLO 词典”。
3. 点击“更新词典”，拉取 Cloudflare GEOFEED 与辅助映射源；locations 会把主源与备用命名源（如 Ashburn、Dallas 这类城市名）合并成一份，覆盖同名机场镇写法。
4. 更新完成后点击“处理词典”，生成综合、IPv4、IPv6 三份本地 COLO 文件。
5. 在同一个分区确认 GEOFEED、综合、IPv4、IPv6 行数与更新时间已经刷新。

只有在输入源 COLO 预筛、国家/COLO 筛选或 MICS 抽样需要地区映射时，才必须先处理 COLO 词典。状态里的“未覆盖”只表示部分 GEOFEED 行暂时没有派生出 COLO，不代表测速失败。

已有旧版词典的安装升级后请重新“更新词典”一次：合并后的 locations 才包含 Ashburn、Dallas、Frankfurt 这类城市名，旧文件里这几种写法会退回“未覆盖”。

## 3. 设置输入源

1. 打开“输入源”页。
2. 在输入组标题行的“+”或来源列表底部选择类型，再填写对应内容：
   - URL 列表：填写远程文本地址。
   - 本地文件：选择本机输入源文件。
   - 手动输入：直接粘贴 IP、CIDR 或域名列表。
3. 输入组设置默认折叠，摘要显示 IP 模式、节点筛选和来源数量；展开后可调整模式、筛选条件、白名单/黑名单或复制当前组。折叠状态会在页面间记忆。
4. 在输入组 IP 模式选择“逐个检查”或“随机抽查”，统一应用到本组已有和新增来源。在来源条目的“更多操作”中编辑、预览、切换 CDN 地址或删除来源。更改来源类型时，再展开来源编辑区的“更多设置（类型）”。使用地区筛选前，请先完成 COLO 词典处理。
5. 点击“检查并预览”确认候选数量。缺少内容、链接格式错误和读取失败的原因会显示在对应来源下方；修改内容后需要重新检查。
6. 点击“更新并保存当前输入组”保存；页面交互和离开页面时也会自动保存。配置类似场景时，使用“复制当前组并编辑”，在副本中修改，原组保留。

输入源会自动跳过空行和 `#` 注释；域名会先解析为 IP 后参与测速。

## 4. 测速

1. 打开“任务看板”。
2. 确认当前输入源组正确，且至少有一个输入源处于启用状态。
3. 点击“启动任务”或“开始探测”。
4. 等待任务依次完成 IP池、TCP测延迟、追踪探测；如果设置为完整模式，还会继续执行文件测速。
5. 打开“当前结果”页查看测速结果、COLO、延迟、下载速度和实际测速端口。
6. 需要保存结果时，在“当前结果”页导出 CSV；文件会写入前面设置的导出目录。

任务运行中可以在“任务看板”暂停或继续。若当前已有任务运行或暂停，需要先完成、继续或终止后再启动新任务。
